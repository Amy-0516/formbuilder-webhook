Integration Steps

  1. Log in to 123formbuilder and open your form
  2. Go to Settings → Integrations
  3. Search for WebHook and click Connect
  4. Paste your Webhook URL into the Script URL field
  5. Optionally enable Use Webhook Mapping to customize field mapping
  6. Save, then Preview the form and submit a test entry
  7. Come back here to view the submission and its translations

Translation Provider

Currently using: mymemory
To change the provider, set the TRANSLATION_PROVIDER environment variable and restart. Supported: mymemory, google-free, auto, deepl, google-cloud, azure

MyMemory Default

Free, no key required. 5000 words/day (50000 with MYMEMORY_EMAIL).

Google Free

Set TRANSLATION_PROVIDER=google-free. No key, but may be blocked in some networks.

Auto (Fallback)

Set TRANSLATION_PROVIDER=auto. Tries Google Free first, falls back to MyMemory.

DeepL

Set TRANSLATION_PROVIDER=deepl and DEEPL_API_KEY.

Google Cloud

Set TRANSLATION_PROVIDER=google-cloud and GOOGLE_CLOUD_API_KEY.

Azure Translator

Set TRANSLATION_PROVIDER=azure, AZURE_TRANSLATOR_KEY, AZURE_REGION.
