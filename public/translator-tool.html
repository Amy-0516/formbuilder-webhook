📌 方法一：书签工具（推荐）

拖拽下方按钮到你的浏览器书签栏，之后每次只需点击一下

🚀 INIU 一键翻译
👆 拖拽到书签栏
如果看不到书签栏，按 Ctrl+Shift+B（Chrome/Edge）或 Cmd+Shift+B（Safari）显示
💡 使用步骤：
1. 登录 123formbuilder，打开你的 INIU 表单
2. 进入 Set up → Language，点击语言的 ✏️ Customize 按钮
3. 在弹出的翻译编辑窗口中，点击书签栏的 "INIU 一键翻译"
4. 等待 1-2 秒，所有翻译自动填入 → 点击 Save 保存
5. 切换到下一个语言，重复步骤 3-4

⌨️ 方法二：控制台脚本（备用）

如果书签不生效，可以复制这段代码到浏览器控制台运行

// 在 123formbuilder Customize 弹窗中，按 F12 打开控制台，粘贴并回车 var s1=document.createElement('script'); s1.src='https://formbuilder-webhook.onrender.com/translations.js'; document.head.appendChild(s1); var s2=document.createElement('script'); s2.src='https://formbuilder-webhook.onrender.com/auto-fill.js'; document.head.appendChild(s2);
💡 使用步骤：
1. 打开 123formbuilder Customize 翻译编辑弹窗
2. 按 F12 打开开发者工具，切换到 Console（控制台） 标签
3. 粘贴上方代码，按 回车
4. 翻译自动填入 → 点击 Save 保存
