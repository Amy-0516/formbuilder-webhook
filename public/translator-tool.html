💡 详细步骤：
1. 登录 123formbuilder，打开你的 INIU 表单
2. 进入 Set up → Language，点击某个语言的 ✏️ Customize
3. 等翻译编辑弹窗完全加载后，按 F12 打开开发者工具
4. 切换到 Console（控制台） 标签
5. 粘贴上方代码，按 回车 执行
6. 如果自动检测到语言，翻译会直接填入；否则会弹出语言选择器
7. 填入后，点击弹窗中的 Save 保存
8. 切换到下一个语言，重复步骤 5-7
⚠️ 如果控制台粘贴不了？
在 Console 中输入 allow pasting 然后按回车，再粘贴即可。
